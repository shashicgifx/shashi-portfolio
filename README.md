# Shashi Singh — AI Video Editor & Motion Graphics Artist Portfolio

A playful, interactive, sketch-styled creative portfolio featuring an interactive 3D physics lanyard ID badge, showreel video player, categorized work showcases, and creative playground.

## ✨ Highlights
- **Interactive 3D Lanyard ID Badge:** Drag, toss, and swing physics simulation with custom pass design.
- **Dynamic Showreel Showcase:** Integrated high-definition video player.
- **Categorized Creative Works:** 6 specialized categories (AI Ad Films, Brand Films, Motion Graphics, Animation, Video Editing, Creative Stills) with custom thumbnails and tool stacks.
- **Responsive & Mobile-Ready:** Fully optimized for iPhone, Android, tablets, and desktop displays.

## 🛠️ Built With
- HTML5 / CSS3 / Vanilla JavaScript
- Physics & interactive drag simulation
- Space Mono, Caveat, Permanent Marker & Patrick Hand typography
- Optimized SVG assets & WebP graphics

## 🚀 Live Deployment
- Designed for seamless 1-click deployment on [Vercel](https://vercel.com) or [GitHub Pages](https://pages.github.com).
